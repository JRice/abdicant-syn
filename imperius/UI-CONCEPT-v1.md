# Imperius panel concept v1

Visual proposal only; the CLAP editor is not implemented by this mockup.

The concept uses the existing 36 host parameters: three large complex-generator controls (Shape, Harmonics, Fold), six associated small modulation/bias controls, a basic waveform selector and tuning, three mixer levels, cutoff/resonance/envelope and LP/HP selection, two LFOs with one Sync button each, two ADSRs, a three-position octave switch and output volume.

Two upper modulation labels distinguish audio-rate sources: AUDIO MOD under Harmonics is HarmonicMod; FOLD MOD is FoldMod. PHASE MOD is the existing PhaseMod parameter. HARM EG and FOLD EG are the independent modulation-envelope depths. LFO AMOUNT controls map to HarmonicLfo and FoldLfo.

The visual direction is a warm silver faceplate, thin rounded black group outlines, black section tabs, silver-center black knobs, restrained amber arcs and narrow walnut cheeks. No preset UI, effects, sequencer, arpeggiator, patch sockets or hardware connections.

Generated using the built-in image-generation tool, with the user's Implexus attachment as a visual-language reference. The exact generation prompt is saved alongside this document as UI-PROMPT-v1.txt.
